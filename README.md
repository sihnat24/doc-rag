# doc-rag

A local document intelligence pipeline for querying heterogeneous document collections — PDFs, spreadsheets, policy pages — with grounded, cited answers.

Built around an agentic workflow where the model selects the appropriate retrieval tool rather than following a fixed pipeline, and explicitly declines when the answer isn't in the corpus.

**Stack:** Python · sentence-transformers · Chroma · Ollama · LangChain

> Work in progress.
